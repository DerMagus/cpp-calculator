# CPP-calculator
cpp-calculator description

Proiect realizat în C++ utilizând funcții și instrucțiunea switch

Permite efectuare adunării, scăderii, înmulțirii și împărțirii

Previne situația în care utilizatorul împarte la 0, solicitând reintroducerea împărțitorului

Previne situația în care utilizatorul introduce un alt operator decât: +, -, * și /.
